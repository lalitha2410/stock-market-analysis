# Stock Market Analysis & Price Prediction

Exploratory data analysis and machine learning models to predict next-day stock prices for AAPL, MSFT, and GOOGL (2020-2024).

## Features
- EDA with statistical summary and missing value analysis
- Data visualizations: price trends, daily returns distribution, correlation heatmap, moving averages
- ML models: Linear Regression (R²=0.9988) and Random Forest (R²=0.9986)
- Feature importance analysis

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Results
Linear Regression and Random Forest both achieved >99% accuracy in predicting next-day stock prices, with current price and 7-day moving average as the strongest predictors.
